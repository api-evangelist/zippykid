# Pressable API v1 Documentation

> Machine-readable API documentation optimized for LLM consumption.

## About Pressable

Pressable is a managed WordPress hosting platform built on Automattic's WP Cloud infrastructure. Features include autoscaling, a global CDN, Jetpack Security, daily backups, SSH/Git/WP-CLI access, and a REST API for programmatic site management. The control panel is at [my.pressable.com](https://my.pressable.com).

## Base URL

`https://my.pressable.com/v1`

## Authentication

All endpoints require Bearer token authentication.
